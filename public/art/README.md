# public/art

Art for Design Your Level, in the Phosphor and Ink look (phosphor green #7CFF9B on #06140B, parchment #E9DCBC, ink #1A120A, sepia #A67C4E). No text, characters or logos in any image. Made 2026-11-04.

Generated with the codex-imagegen skill: Codex built-in image tool (ChatGPT Plus, $0) or, where marked "API", the OpenAI Image API (gpt-image-2.5-flare, high, true alpha). API spend for this set: $0.16. Transparent Codex outputs were chroma-keyed, then despilled (magenta fringe removed, 1 px alpha erode + feather). All PNGs are trimmed to their content and quantized to 256 colours (visually checked at 4x on dark and parchment). JPEGs are progressive, q78-82.
